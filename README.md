# Ферма 1.0

Локальная одиночная браузерная игра: три культуры, курица и покупаемая корова, кормление, яйца/молоко, рынок, расширение с шести до двенадцати грядок и сохранение прогресса.

## Запуск

Из папки игры (в скачанном репозитории — из его корня) запустите Python 3:

```bash
python3 -m http.server 8767 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8767 в браузере того же компьютера. Остановка — Ctrl+C в терминале. Если порт занят, выберите другой свободный порт и измените его также в адресе браузера. Установка пакетов не нужна. Запуск двойным щелчком по index.html не поддерживается из-за ES modules.

На физическом телефоне адрес 127.0.0.1 относится к самому телефону; доступ с другого устройства этой командой не предоставляется. Для такого просмотра нужен отдельно согласованный способ размещения или доступа, без автоматического изменения firewall и сетевых настроек.

## Как играть

1. Нажмите пустую грядку, выберите семена. Их цена списывается при посадке; пшеница растёт 20 секунд, морковь 40, кукуруза 60.
2. Соберите готовый урожай. Во вкладке «Животные» покормите курицу пшеницей; через 30 секунд заберите яйцо.
3. На рынке продавайте продукцию по одной единице. Оставляйте пшеницу для корма.
4. Открывайте новые грядки за 40 монет и купите корову за 100. Корова потребляет 2 пшеницы и через 60 секунд даёт молоко.

Урожай не портится, животные не умирают. Если ресурсов совсем не осталось, на вкладке грядок появятся бесплатные семена для продолжения.

## Сохранение и ограничения

Прогресс сохраняется после каждого успешного действия под ключом farm.save.v1 в этом браузере и для этого адреса. Очистка данных, смена браузера или адреса не переносит ферму. При запрете хранилища можно играть в памяти с предупреждением. Повреждённая/будущая версия не сбрасывается автоматически; начало новой фермы требует явного подтверждения в интерфейсе. При конфликте вкладок загрузите актуальное сохранение.

Созревание учитывает время закрытой страницы, но автоматически не собирает урожай и не кормит животных. Системные часы влияют на готовность. Аккаунтов, синхронизации, полноценного офлайн запуска и мультиплеера нет. Физические устройства и реальная длительность освоения ещё не проверены.

## Структура и проверки

- catalog.mjs — культуры, животные, продукты и баланс.
- model.mjs — состояние, валидация, миграция и атомарные игровые команды.
- storage.mjs — сохранение, ошибки и обнаружение конфликта.
- app.mjs, art.mjs, styles.css, index.html — интерфейс и локальная векторная графика; emoji зависят от системного шрифта.
- test.mjs — семь тестов ядра/хранилища, включая 10000 случайных команд. Запуск из папки игры: `node test.mjs`.
